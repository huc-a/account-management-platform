# account-management-platform

私人账号管理平台：用主密码加密，管理多个账号和凭证。

本仓库是该项目的说明仓库，不存放任何真实账号、密码或保险库数据。平台本体运行在作者的私人 Muse 环境中，不对外公开链接。

## 它能做什么

- **主密码解锁**：第一次打开时设置主密码，之后每次打开都要输入主密码才能进入。
- **自动锁定**：无操作 5 分钟后自动锁定，需要重新输入主密码解锁。
- **账号管理**：添加、编辑、删除账号，字段包括名称、分类、用户名、密码、网址、备注和常用标记。
- **查找更方便**：支持按名称搜索，按分类和常用筛选。
- **密码操作**：详情里可以显示 / 隐藏密码，一键复制密码。
- **随机密码生成**：添加账号时内置随机密码生成器，可以调整长度和字符类型，并给出强度提示。
- **修改主密码**：修改后，里面的密码会自动全部重新加密。
- **忘记主密码**：主密码忘了无法恢复，只能经过二次确认清空保险库，重新开始。

## 安全设计

- 密码先在设备上加密，再保存：使用主密码派生的密钥，算法为 PBKDF2 + AES-256-GCM。
- 服务端只保存密文，主密码不会离开设备。
- 在没有原生 Web Crypto 接口的环境里，会自动切换到内置的纯 JavaScript 加密实现，格式与原生实现一致，两种环境下建的保险库可以互通。
- 不要把真实账号密码发在聊天记录、Issue 或任何公开地方，应直接在应用内添加和管理。

## 使用方法

1. 打开私人账号管理平台应用。
2. 第一次使用时设置一个自己记得住的主密码，并确认“忘了无法恢复”的提示。
3. 解锁后添加账号：填写名称、分类、用户名、密码、网址和备注，必要时使用随机密码生成器。
4. 日常使用时通过搜索或分类找到账号，在详情里复制密码。
5. 离开时可以手动锁定，5 分钟无操作也会自动锁定。

## 本地运行

这是一个无需后端的静态网页项目，不依赖任何第三方库：

```bash
cd account-management-platform
python3 -m http.server 8000
```

然后在浏览器打开 http://localhost:8000 。

直接用 `file://` 打开时，部分浏览器可能不提供 Web Crypto 加密接口，建议用上面本地服务器方式打开。数据只保存在浏览器本地存储中，不会上传到服务器。
